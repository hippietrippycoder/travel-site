How the Africa Tour site gets built and shipped

A record of the actual system behind africatour.hippytrippytrader.com — nine static pages, a design system built up over many small rounds, and the exact pipeline that turns a chat request into a deployed page.

9 static HTML pages Cloudflare Workers hosting Git-connected auto-deploy No framework, no build step Built Sep 2026

From a chat message to a live page

Every change follows the same two-phase loop: a fast inner loop where edits get made and checked without touching the live site, and a deliberate outer step — done by hand, on purpose — that actually ships it.

What it's built with

No framework and no build step anywhere in this stack — every page is a single self-contained HTML file, which is what makes the "edit → zip → push" loop above possible at all.

Vanilla HTML / CSS / JS

Each of the 9 pages inlines its own <style> block and a few lines of JS for the mobile sidebar toggle. No React, no bundler, no npm install.

Cloudflare Workers

Serves the static HTML files globally under africatour.hippytrippytrader.com. No server, no database.

GitHub, git-connected

Repo hippietrippycoder/travel-site. Cloudflare watches the main branch and redeploys on every push — no manual "deploy" click.

Playwright QA

Every edit gets checked headless in Chromium at desktop and mobile widths, in light and dark mode, for horizontal overflow and JS errors, before it's ever shown to you.

CSS custom properties

Colors, shadows and radii are tokens (--bg, --accent, …), swapped automatically for dark mode via prefers-color-scheme.

Fraunces · Karla · JetBrains Mono

One serif for headings, one grotesk for body text, one mono for labels and stats — loaded from Google Fonts in every page.

Design system

Every page shares the same nine color tokens and three typefaces, so the checklist pages, the itinerary and the home page all read as one site.

What we built, round by round

The site started as nine plain pages and got its personality through many small, reviewed rounds. A few of the more notable ones:

The header & hero. Added flag emoji next to each country in the route line, then had to make all five country names fit on a single line without losing the flags — a flexbox quirk (a nowrap child was silently forcing its parent to grow) got fixed with one min-width:0. The title itself got reworked from "AFRICA FIVE / NATION TOUR" to a cleaner "AFRICA / FIVE NATION TOUR" break.

Trivia, grounded in the real itinerary. Every stat on the home page — coastline driven in Mauritius, number of beaches, national parks along the way — was pulled from the actual day-by-day plan, never invented. When a requested addition (Black River Gorges NP) turned out not to be an actual stop, that got flagged and confirmed before adding it rather than added silently.

From "bricks" to a bento grid. The original trivia tiles were uniform boxes that read as "bricks arranged." They were rebuilt with CSS Grid grid-template-areas — a hero tile spanning 2×2, a wide tile spanning 2×1 — redefined at a 640px breakpoint so mobile gets its own 2-column layout instead of a squashed desktop one.

The sidebar found its shape. "Trip Home" became "Home"; a new Financials group was carved out for the budget page; the Day-by-Day links got reordered; every label was set to uppercase and then tuned (font-size, padding, letter-spacing) until the longest one, "Weather Forecast Daily," fit on one line without wrapping.

The top-left badge, three tries. The "Africa Five Nation Tour / 24 Sep–12 Oct" text block came out first for a single compass icon, then — after review — for the current mark: six small bordered icons (paw, mountain, pin, palm, sun, continent outline) in a row, sized to fit the 238px sidebar with room to spare. Each option was mocked up as a sample sheet and shown before being wired in.

Fixing the mojibake bug. Four pages were rendering garbled characters in place of dashes, dots and flag emoji. The bytes on disk were valid UTF‑8 the whole time — the actual cause was that those four files were missing their <!doctype html><html><head><meta charset="UTF-8"> wrapper entirely, so the browser was guessing the encoding. Adding the standard document head fixed all four without touching a single character of content.

Shipping a change

The outer step is deliberately manual — nothing goes live until you run this yourself:

# unzip the delivered file, then from the repo folder:
cd ~/Downloads/trip-site_1
cp trip-site_N/*.html .
git add *.html
git commit -m "describe the change"
git push

Cloudflare picks up the push to main within a minute or two and the live site updates automatically — no dashboard clicks required.
